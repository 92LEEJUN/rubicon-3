# 요구사항 (Requirements) — always-present companion

## 개요

"**언제든 에이전트가 곁에 있다**"는 느낌을 주는 컴패니언 경험. 대화 연속성(ADR-0040) 위에
**이어가기·미해결 스레드 챙김·(엄격 게이트) 선제 재관여·교차기기/시간 인지**를 얹는다.
토대 문서: `docs/operations.md` §4-1(연속성·메모리) · `docs/architecture.md` §10(선제 파이프라인) · ADR-0040(컴팩션)·ADR-0028(흐름 전환/복원) · R9(전역 패널)·R12(이력)·R25(해결확인)·R26(빈도)·R19(동의).

## 요구사항 목록

### 요구사항 1: 이어가기 (resume)
**User Story:** 사용자로서, 패널을 다시 열었을 때 끊김 없이 이어가길 원한다, 그래서 매번 처음부터 설명하지 않아도 된다.

**수용기준:**
1. WHEN 사용자가 전역 패널을 (재)열 때 THEN 시스템은 영속 메모리(롤링 요약 + 구조화 사실)와 보류 흐름(`suspended_flow`)을 복원해 이어가기 맥락을 제시해야 한다 (SHALL).
2. IF 마지막 활동 후 시간이 경과해 working 세션(`sess:{sid}` TTL)이 만료됐어도 THEN 시스템은 **영속 메모리에서** 복원해야 한다 (SHALL).
3. WHEN 이어가기 맥락을 제시할 때 THEN 시스템은 사용자가 **'새로 시작'** 을 선택할 수 있게 해야 한다 (SHALL).

### 요구사항 2: 미해결 스레드 추적 (open-loop)
**User Story:** 사용자로서, 진행 중이던 일을 에이전트가 기억하고 챙겨주길 원한다, 그래서 내가 놓쳐도 이어진다.

**수용기준:**
1. WHEN 미해결 이슈·진행 중 주문·보류 흐름이 생길 때 THEN 시스템은 이를 **open-loop**로 추적해야 한다 (SHALL).
2. WHEN 사용자가 돌아올 때 THEN 시스템은 열린 open-loop를 **우선순위로 요약** 제시해야 한다 (SHALL).
3. WHEN open-loop가 해소(R25 해결확인·주문 배송완료·사용자 닫음)될 때 THEN 시스템은 해당 open-loop를 **닫아야** 한다 (SHALL).

### 요구사항 3: 선제 재관여 (proactive, 엄격 게이트)
**User Story:** 사용자로서, 중요한 후속은 에이전트가 먼저 알려주길 원한다, 그래서 신경 쓰지 않아도 제때 챙겨진다.

**수용기준:**
1. WHEN open-loop·이벤트(부품 입고·해결확인 시점 등)가 트리거될 때 THEN 시스템은 선제 재관여 메시지를 **생성할 수 있어야** 한다 (SHALL).
2. IF 동의(`opted_in`/`Consent`) 또는 빈도 한도(R26)를 충족하지 못하면 THEN 시스템은 선제 메시지를 **보내지 않아야** 한다 (SHALL).
3. WHILE 가치가 낮거나 중복일 때 시스템은 선제를 **억제**해야 한다 (SHALL) — 피로 방지.
4. WHEN 사용자가 선제 메시지를 탭할 때 THEN 시스템은 해당 맥락으로 대화를 이어야 한다 (SHALL) — proactive→reactive(architecture §10).

### 요구사항 4: 교차기기 정체성
**User Story:** 사용자로서, 어느 기기에서 열든 같은 기억으로 이어지길 원한다.

**수용기준:**
1. WHEN 같은 사용자가 다른 기기/세션에서 열 때 THEN 시스템은 **user 단위 메모리**로 동일한 연속성을 제공해야 한다 (SHALL).
2. WHEN 메모리에 접근할 때 THEN 시스템은 `user_id` + Consent 스코프로 가드해야 한다 (SHALL, R15·R19).

### 요구사항 5: 시간 인지
**User Story:** 사용자로서, "어제/지난주" 같은 시간 맥락이 자연스럽길 원한다.

**수용기준:**
1. WHEN 경과 시간이 있을 때 THEN 시스템은 상대 시간(어제/지난주 등)을 인지해 요약·인사에 반영해야 한다 (SHALL).

### 요구사항 6: 프라이버시 / 동의 (cross-cutting)
**User Story:** 사용자로서, 내 기억·선제가 동의 범위 안에서만 쓰이길 원한다.

**수용기준:**
1. IF `Consent.scopes`에 관련 권한이 없거나 opt-out이면 THEN 시스템은 선제를 중단하고 메모리 개인화 사용을 제한해야 한다 (SHALL).
2. WHEN 사용자가 삭제를 요청할 때 THEN 시스템은 메모리·open-loop를 cascade 삭제해야 한다 (SHALL, R19).
