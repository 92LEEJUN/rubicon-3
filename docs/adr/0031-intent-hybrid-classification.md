# ADR-0031: 의도 분류 = LLM 구조화 출력 + 규칙 가드레일 (하이브리드)

- **상태**: 채택
- **관련**: `docs/orchestration.md` §4, `docs/llm-policy.md` §5, `backend/app/orchestrator/classify.py`

## 배경
의도 분류는 정확해야 하고, 특히 **민감 경로(주문·핸드오프)** 는 오분류 시 위험하다.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | **LLM만** | 자연어 이해 강함 | 비결정·민감 경로 오분류 리스크 |
| B | **규칙 엔진만** | 결정적·빠름 | 자연어 변형에 취약 |
| **C (선택)** | **하이브리드** — LLM 구조화 출력(JSON 스키마 강제) + 규칙 가드레일 | 이해력 + 핵심 경로 안전 | 두 단계 |

## 결정
**C.** 구조화 출력으로 분류·분해하고, **핵심 의도(주문·핸드오프)는 LLM에만 의존하지 않고 규칙으로 한 번 더 검증.** 구현은 `RuleBasedClassifier`(결정적, 테스트) ↔ `OpenAIClassifier`(실) 교체(ADR-0020).

## 기각 이유
- A: 민감 경로를 LLM 단독에 맡기면 오분류 리스크.
- B: 규칙만으론 자연어 변형·복합 질문을 놓친다.

## 결과/영향
규칙 분류기가 결정적 테스트 경로(LLM_BACKED off)를 제공 → BE 테스트가 LLM 없이 동작.
