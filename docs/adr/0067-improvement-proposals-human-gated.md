# ADR-0067: 자기개선 = "개선 제안 엔진"(propose-only, 휴먼 인 더 루프, 자동 적용 금지)

- **상태**: 채택(스펙 — 구현 후속)
- **관련**: [`specs/improvement-proposals/`](../../specs/improvement-proposals/requirements.md), ADR-0052(가드레일 — 안전 게이트 동형), ADR-0066(컴패니언 — 신호 공급), ADR-0064(실험 A/B = S8), ADR-0011(조건부 리뷰), [analytics.md](../analytics.md)(R28), [`docs/user-journey.md`](../user-journey.md)(V6·P5)
- **비고**: 0053~0066 사용 중 → 본 결정은 0067.

## 배경
"측정 없이 개선 없음"(V6). 대화 결과·라우팅 신뢰도·전환율·만족도·실험(S8) 결과를 모아 제품을 **상시
개선**하는 피드백 루프가 필요하다. 그러나 **AI가 자기 프롬프트·규칙·템플릿을 자동으로 바꾸면** 안 된다
— 환각·드리프트·신뢰·안전 위험이 크고, 되돌릴 수 없는 변경이 조용히 누적될 수 있다. 따라서 "어디까지
자동화하고 어디서 사람이 개입하는가"를 결정해야 한다.

## 결정
자기개선을 **"개선 제안 엔진(Improvement Proposal Engine)"** 으로 둔다 — **제안만 만들고, 적용은
사람이 한다.** (토글 `SELF_IMPROVE` 기본 off=회귀 불변, 결정적·Mock 허용.)

- **불변 원칙: 자동 적용 경로를 두지 않는다.** 엔진은 프롬프트·분류 규칙·템플릿·게이트를 **직접 수정할 수
  없다**. 산출물은 오직 **증거 기반 제안(proposal)** 이다. (가드레일 ADR-0052와 동형의 안전 원칙 — 경계에서
  사람이 결정.)
- **4단계 파이프라인**:
  1. **신호 수집(SignalCollector)** — 대화 결과(해결/핸드오프/이탈)·저신뢰 라우팅·clarify 빈발·템플릿
     전환율·만족도(ADR-0066)·실험(S8) 결과. analytics(R28)·Engagement(R29) 재사용.
  2. **제안 생성(ProposalEngine)** — 패턴 탐지 → **구조화 제안**(증거·영향 추정·변경 후보). 예: "의도 X
     오분류 30% → 분류/프롬프트 후보", "템플릿 Y 전환 낮음 → CTA 후보". 결정론 규칙 1차(실 LLM 분석은 선택).
  3. **휴먼 리뷰 큐(ReviewQueue)** — 운영자(P5)가 보는 백로그. 상태기계
     `제안됨 → 검토중 → (승인|기각) → (검증중) → 적용`. **적용은 사람만**.
  4. **실험 검증 연계(ExperimentBridge → S8)** — 승인된 제안은 **S8 실험(ADR-0064)으로 A/B 검증**한 뒤
     사람이 채택·적용. 검증은 자동, **채택·적용은 사람**.
- **감사·되돌리기** — 제안·리뷰 결정·적용은 감사 로그(ADR-0061/S7)에 남긴다. 적용은 사람이 코드/설정 변경
  (PR)로 수행 → git 이력으로 추적·롤백.

## 대안 / 기각
- **자동 적용(self-modifying)** — 루프는 빠르나 환각·드리프트·신뢰·안전·되돌리기 불가. **강하게 기각** —
  되돌릴 수 없는 자기수정은 본 제품 안전 원칙(확인 게이트 R17·가드레일 0052)과 정면 충돌.
- **분석만(제안 없음)** — 대시보드만 보고 사람이 알아서. 루프가 안 닫히고 인사이트가 행동으로 안 이어짐.
  **기각** — 제안(구조화·증거·변경후보)까지 만들어야 사람이 빨리 결정.
- **승인 즉시 자동 적용** — 사람이 승인 버튼만 누르면 시스템이 반영. 편하지만 검증 없이 반영되어 회귀
  위험. **기각** — 승인 후 **S8 실험 검증**을 거쳐 사람이 최종 채택(채택한 사용자 결정과 정합).

## 영향
- **user-journey.md V6 / P5** — 운영자의 개선 루프를 구체화. 신호→제안→리뷰→검증의 백오피스 흐름.
- **ADR-0066 연계** — 만족도·미해결·이탈을 신호로 공급(두 트랙이 루프).
- **ADR-0064(S8) 연계** — 승인 제안의 A/B 검증 다리. **ADR-0061/S7 감사** — 결정 추적.
- **계약·안전** — 엔진은 외부 노출 최소(운영 내부). 사용자 대면 동작은 변경 없음(제안은 백오피스).
- 구현은 `specs/improvement-proposals/design.md`·`tasks.md`. **자동 적용 코드 경로는 구현하지 않는다**(원칙).
