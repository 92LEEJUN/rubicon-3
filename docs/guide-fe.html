📱 Frontend (React Native)

FE 완성 가이드

BE 계약(템플릿 모델)을 렌더하는 앱. 라우팅 판단은 하지 않는다. 이 문서 하나로 FE 작업에 필요한 계약이 모두 들어 있다.

책임화면템플릿14종/chat 프로토콜엔드포인트상태·훅분석트랜스포트복합 렌더주의

01책임 / 경계

✅ 한다

  • 화면(S1 홈·S2 CS·S3 채팅·S4 브릿지) 렌더
  • 템플릿 14종 + 섹션 스택(복합) 렌더
  • 스트리밍 표시·멀티모달 입력
  • CTA 처리(대화형→/chat, 커밋→엔드포인트)
  • 상태/훅, 분석 이벤트 발생(동의 게이트)

🚫 안 한다

  • LLM/도메인 라우팅 판단(BE 몫)
  • 브릿지/패널 분기 결정(BE가 surface 반환)
  • 비즈니스 로직·집계
  • 카탈로그 브라우즈 화면(없음 — 카드/챗만)

02화면 (저충실도)

디자이너 애셋 전엔 토큰/플레이스홀더. 레이아웃·흐름만, 비주얼 아님.

화면용도
S1 홈개인화 선제안(home_summary)·전역 채팅 FAB
S2 CS내 기기·증상/모델로 찾기·상담/방문·이력
S3 채팅 패널(전역)어디서든 오버레이. text+섹션 템플릿+media+cta
S4 브릿지 모달카드 탭 시 간단 정보(대화 미진입)
카드 탭 → BE가 surface 결정: 간단→S4 브릿지 모달 / 복잡→S3 패널. FE는 surface만 보고 띄움. 카탈로그 브라우즈 화면은 없음(제품=카드/챗).

04대화 — WebSocket /chat

# 클라이언트 → 서버
user_message      { session_id, text, media[], screen_context }   # 자유 입력(R1·R10), 화면 맥락(R9-4)
interaction_reply { session_id, ref, kind, payload }              # choices/confirmation/booking 회신

# 서버 → 클라이언트 스트림 청크 (점진적, R14)
delta     { text }                                  # 리드/섹션 텍스트 토큰
section   { section: MessageSection }               # 섹션 1개(복합이면 의도 순서대로 여러 번)
flow      { active_flow }                           # 흐름 배지(R6)
done      { message_id }                            # 종료(누적 sections로 확정)
error     { code, fallback }                        # 폴백(R13)

MessageSection = { label, intent, template:Template, ctas:[Cta], handled }  # handled=false → 미처리(R7-3)
대화형 CTA(제안 칩·인터랙션 회신·설명 요청)는 /chat 재진입(LLM 가능). 되돌릴 수 없는 커밋(결제·주문·예약 확정)만 결정적 엔드포인트(LLM 미경유).

05결정적 엔드포인트 (조회·커밋)

엔드포인트메서드요청 → 응답

08스트리밍 트랜스포트

우선안: WebSocket. 양방향(회신·중단·타이핑), RN 내장 지원, 실시간 확장. ChatTransport 추상화 뒤에 두어 교체 가능.

안판단
WebSocket(우선)양방향·내장·실시간 확장. 재연결·백그라운드 관리 필요
SSE미선택 — RN EventSource 미지원 + 단방향(회신 채널 이원화)
chunked fetch미선택 — RN 스트리밍 fetch 불안정

⚠️ WebSocket 스파이크(재연결·백그라운드·단절) 결과로 보정 가능.

09복합 응답(R7) 렌더

한 어시스턴트 턴 = 의도별 sections[] 세로 스택. 우선순위(안전/CS 먼저) 순서로 스트리밍.

🧑 "세탁기 물 안 빠짐 해결법 + 정수필터/HEPA 주문"
🤖 ─ 🛠 세탁기·배수(5C)   → guide_steps        (섹션1, handled)
   ─ 🛒 정수필터          → product_card+[주문]  (섹션2, handled)
   ─ ⚠ HEPA 필터          → text "품절" +[입고알림] (섹션3, handled=false)
   ─ ✅ "2건 안내, HEPA는 품절이라 입고 알림으로 대신했어요"  (요약)

10주의 / 결정

  • 카드 탭 → surface: BE가 bridge(S4)/panel(S3) 동적 결정. FE는 렌더만.
  • CTA 두 경로: 대화형→/chat(LLM 가능) / 커밋→엔드포인트(LLM 미경유).
  • 복합=섹션: sections[](라벨·handled). 단발=1개.
  • 상태 4종: 모든 화면·템플릿에 로딩(스켈레톤)·빈·에러·재시도.
  • 보안 저장: 토큰 Keychain/Keystore. 앱 번들 시크릿 금지.
