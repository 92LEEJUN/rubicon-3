# ADR-0018: 후보3 단계 타임아웃·부분 폴백·fine abort (보류)

- **상태**: 보류
- **관련**: `docs/operations.md` §8·§12·§14, ADR-0016

## 배경
견고성·비용 레버: ⓐ 에이전트 **단계별 타임아웃** + 부분 폴백(R13) ⓑ 클라이언트 끊김 시 진행 중 LLM **abort**(비용 절감).

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | **지금 구현** | 견고성·비용 절감 | 즉시 체감 작음, fine abort는 async 의존 |
| **B (선택)** | **보류** | 범위 집중 | 견고성·비용 방어 미실현 |

## 결정
**B — 보류.**

## 근거 / 기각 이유
- **즉시 체감이 작다** — 지연 단축이 아니라 실패/과부하 시의 견고성·비용 절감 중심.
- **abort 입도가 실행 모델에 종속** — async 전환(ADR-0016) 후 **fine abort**(in-flight 취소)가 깔끔. 지금 서두를 이유가 적다.
- 사용자가 후보1·3을 함께 보류하기로 명시.

## 결과/영향
async 토대(ADR-0016)는 이미 갖춰져, 추후 fine abort·단계 타임아웃을 낮은 비용으로 추가 가능. 개념은 ADR-0008(멀티에이전트 단계 타임아웃)에 기록됨.
