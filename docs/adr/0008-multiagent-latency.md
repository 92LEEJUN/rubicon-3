# ADR-0008: 멀티에이전트 지연 고려 반영 (SLA 재정의·N배 비용)

- **상태**: 채택
- **관련**: `docs/operations.md` §14·§14-1, `docs/orchestration.md` §10, ADR-0005·0007

## 배경
실제 멀티에이전트(슈퍼바이저·서치·리뷰 + DB)는 LLM 호출이 **직렬 누적**돼 7~15s(이후 실측 ~21s, §14-1)가 난다. "최종답만 스트리밍" 가정이 깨지고 단일 SLA·동시성 모델이 안 맞는다.

## 후보안
| 안 | 내용 |
|---|---|
| 미반영 | 기존 단일 경로 가정 유지(7~15s 현실 무시) |
| **반영 (선택)** | 뼈대(2-플레인·세션격리·세마포어·백프레셔 무노출)는 유지하되 멀티에이전트 특성을 **추가 반영** |

## 결정
**반영.** 추가 사항:
1. **SLA 진행 지표 재정의**(ADR-0005 확장) — 첫 의미있는 섹션 ≤2~3s, 완료는 **별도 등급 p95 ≤15~20s**.
2. **동시성·비용 N배** — 워커 7~15s 점유 + 턴당 LLM 3~5회 → 동시성 상한↓·오토스케일 조기·레이트리밋 ×N·Phase B 시급성↑.
3. **단계별 타임아웃 + 부분 폴백**(개념; 구현은 보류 ADR-0018).
4. **관측성** — 에이전트별 스팬·단계 지연.
5. 릴레이는 Streams 유리하나 **보류 유지**(ADR-0007).

## 기각 이유
- 미반영: 실측이 SLA 등급 상단을 넘겨(§14-1) 그대로 두면 빈 대기·SLA 위반.

## 결과/영향
대응 레버(병렬화·다단계 스트리밍)는 ADR-0014~0017로 이어진다.
