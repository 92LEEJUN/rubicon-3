# 유저 시나리오 (User Scenarios)

요구사항(`../requirements.md`)을 **end-to-end 흐름**으로 강화하고 갭을 발굴하는 시나리오 모음.
성격이 다른 내용을 파일로 분리했다. 단일 출처는 requirements.

| 문서 | 성격 | 내용 |
|------|------|------|
| [`personas.md`](./personas.md) | 기준 | 페르소나 P1~P4 |
| [`flow-main.md`](./flow-main.md) | 시나리오 | 메인 풀 저니(이상→해결→주문→사후) |
| [`flow-branches.md`](./flow-branches.md) | 시나리오 | 대안·분기 |
| [`flow-edge.md`](./flow-edge.md) | 시나리오 | 엣지·예외 |
| [`classification.md`](./classification.md) | 프레임워크 | Proactive / Reactive / Hybrid |
| [`o2o.md`](./o2o.md) | 시나리오(도메인) | O2O 양방향 맵 |
| [`gaps.md`](./gaps.md) | 분석 | 갭 분석 + 다음 단계 |

> 구체 데이터 기반 풀 저니(J1~J5)는 [`../journeys.md`](../journeys.md).
> 화면/템플릿은 `docs/wireframes.md`·`docs/response-templates.md`, 흐름은 `docs/diagrams.md`.
