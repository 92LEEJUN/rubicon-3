1아키텍처 — 3계층 · Port↔Mock 경계

FE(RN Web)는 BFF만 본다. BFF는 표면·정형화·중계(비즈로직 없음), BE 도메인이 라우팅·오케스트레이션. 외부 연동은 Port 뒤 Mock↔실 교체.

2대화 흐름 — 디스패치 3경로 + 멀티에이전트

한 진입(/turn)에서 토글로 3경로 공존: 결정적(기본·회귀0) / 단일 tool-loop / 슈퍼바이저-워커. 멀티에이전트는 순차·단일 패스, 다단계 스트리밍.

6운영 · 스케일

2-플레인(인터랙티브/비동기) · 동시성 Phase A→B · 멀티에이전트 지연 실측.

동시성 Phase A

async 전환·LLM 세마포어·백오프. 실측: 4턴 동시 ≈ 1턴 시간(스레드-당-턴 점유 제거).

Phase B 미착수

Redis 세션격리·토큰버킷·스트리밍 릴레이·무상태 워커. 릴레이 Streams vs Pub/Sub 보류.

멀티에이전트 지연 실측

복합 순차 15~21s(최대~21s). 대응: 다단계 스트리밍(체감)·병렬화(보류).

백프레셔 UX 확정

혼잡·순번 무노출 + 점진 렌더. 능동 강등 제외(품질 일관).
