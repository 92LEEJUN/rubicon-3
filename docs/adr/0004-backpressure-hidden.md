# ADR-0004: 백프레셔 무노출 + 점진 렌더 (적응형 강등 제외)

- **상태**: 채택
- **관련**: `docs/operations.md` §11

## 배경
과부하 시 사용자 경험을 어떻게 다룰지. 대기·순번·혼잡을 드러낼지, 품질을 낮춰서라도 빨리 답할지.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (선택)** | **혼잡 무노출 + 점진 렌더** — 결정적 섹션/스켈레톤 즉시 → LLM 텍스트 뒤이어 스트리밍 | 체감 지연 가림, "다른 사용자 때문" 신호 없음 | 총 완료시간은 그대로 |
| B | 대기/순번/혼잡 **노출** | 정직한 신호 | UX 저하, "남 때문에 느림" 인상 |
| C | **적응형 강등** — 혼잡 시 경량 모델/결정적 응답으로 전환 | 지연 방어 | **품질 비일관**(같은 질문 다른 품질) |

## 결정
**A.** 혼잡·대기·순번을 일절 노출하지 않고 점진 렌더로 체감을 가린다. 인디케이터 문구는 **항상 답변 중심**("답변을 정리하고 있어요"), 시스템·대기·순번 언급 금지.

## 기각 이유
- B: 순번·혼잡 노출은 UX를 해치고 "다른 사용자 때문" 신호를 준다.
- C: 적응형 강등은 **품질 일관성**을 깨므로 이번 채택에서 제외(추후 후보로만 남김).

## 결과/영향
SLA(ADR-0005)가 "능동 강등 없이 목표+오토스케일로 운영"이 되는 직접적 근거. 다단계 스트리밍(ADR-0015)이 이 점진 렌더의 실효 수단.
