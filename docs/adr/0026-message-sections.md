# ADR-0026: 복합 응답 = Message + sections[] (handled 구분)

- **상태**: 채택
- **관련**: `docs/response-templates.md` §5, `docs/data-model.md` §3, R7

## 배경
복합 질문(R7)은 한 응답에 여러 의도(해결+주문 등)가 섞인다. 의도별로 답을 분리 표시하고 **미처리 의도**를 구분해야 한다.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | **메시지별 단일 템플릿** | 단순 | 복합 의도를 한 응답에 못 담음 |
| **B (선택)** | **메시지 1개 = `text` + `sections[]`**(섹션별 template+ctas+label+handled) | 의도별 분리·순서·미처리 구분 | 구조 복잡 |
| C | **메시지를 여러 개로 쪼갬** | 단순 누적 | 한 턴의 응집성·순서 표현 약함 |

## 결정
**B.** 단발=섹션 1, 복합=섹션 N(우선순위 순서). **미처리 의도는 `handled:false` 섹션**(폴백 text)으로 구분. FE는 섹션을 세로 스택 + 의도 라벨.

## 기각 이유
- A: 복합 질문을 한 응답에 담을 수 없다.
- C: 한 턴 응답의 응집성과 우선순위 순서를 잃는다.

## 결과/영향
멀티에이전트 조립(ADR-0009·0012)의 handled/unhandled 출력과 정합. 구조화 Template(ADR-0025) 위에 선다.
