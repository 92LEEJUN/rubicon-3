# 와이어프레임 / 화면 명세 (Wireframes)

> **기반 문서 (공유).** 저충실도(레이아웃·구조·흐름) 화면 명세다. **비주얼 디자인이 아니다** —
> 디자이너 애셋은 이 구조 위에 입혀진다. 컴포넌트·CTA·상태는 `docs/response-templates.md`,
> 화면 동작·트랜스포트는 `docs/frontend-architecture.md`, 흐름은 스펙 design을 따른다.
>
> ASCII 박스는 **영역 배치 기준**일 뿐 픽셀·스타일이 아니다. (조율) 디자이너가 와이어프레임을
> 별도로 그린다면 이 문서는 명세 참조로만 쓰고 중복 작성하지 않는다.

## 1. 화면 인벤토리

| # | 화면 | 목적 | 요구사항 |
|---|------|------|----------|
| S1 | 홈 | 첫 진입, 개인화 선제안·종합 요약 | R9-2·R5·R8 |
| S2 | CS 페이지 | 문제 해결·상담·방문 진입 | R9-3·R3·R18 |
| S3 | AI 채팅 패널(전역) | 어디서든 대화, 멀티모달·템플릿·CTA | R9-1·R10·R11·R14 |
| S4 | **브릿지 모달** | 카드 탭 시 간단 정보 설명(대화 미진입) | R9 |
| — | (채팅 내) 템플릿 렌더 | 14종 템플릿이 메시지로 표시 | R11 |

> 전역 채팅 패널(S3)은 **모든 화면 위에 오버레이**로 뜬다(바텀시트/모달). 별도 라우트가 아님.
> 카드 탭 → **간단하면 S4 브릿지 모달 / 복잡하면 S3 패널**(BE 동적 판단, `response-templates.md` §9).

## 2. S1 — 홈

`home_summary` 템플릿 데이터를 화면화한다(R9-2).

```
┌───────────────────────────────┐
│ 안녕하세요, OOO님            🔔 │  헤더 + 알림
├───────────────────────────────┤
│ ⚠ 선제 알림 (alerts)          │  device_status 요약
│ ┌───────────────────────────┐ │  - 이상/소모품
│ │ 세탁기 · 필터 교체 시기    │ │
│ │           [지금 주문] [보기]│ │  CTA: reorder
│ └───────────────────────────┘ │
├───────────────────────────────┤
│ 추천 (recommendations)        │  recommendation_list
│ ┌─────┐ ┌─────┐ ┌─────┐      │  product cards (가로 스크롤)
│ │카드 │ │카드 │ │카드 │ …    │
│ └─────┘ └─────┘ └─────┘      │
├───────────────────────────────┤
│ 바로가기 (shortcuts)          │  intent 진입칩
│ [내 기기] [주문내역] [상담]   │
├───────────────────────────────┤
│                          ( 💬 )│  전역 채팅 FAB → S3
└───────────────────────────────┘
```

- **상태:** 로딩=스켈레톤 카드 / 빈=알림 없을 때 "이상 없음" + 추천만 / 에러=재시도 배너(R13).
- 알림 0건이어도 추천·바로가기는 노출. 미연동 사용자는 연동 유도 카드.

## 3. S2 — CS 페이지

문제 해결·상담·방문의 진입 허브(R9-3). 대부분 실제 처리는 채팅(S3)으로 이어진다.

```
┌───────────────────────────────┐
│ ← 고객지원                     │
├───────────────────────────────┤
│ 내 기기                       │  연동 기기 목록
│ ┌───────────────────────────┐ │  device_status 진입
│ │ 세탁기   상태: 점검 필요 ⚠ │ │
│ │ 냉장고   상태: 정상        │ │
│ └───────────────────────────┘ │
├───────────────────────────────┤
│ 무엇을 도와드릴까요?          │
│ [증상으로 찾기] [모델로 찾기] │  → 채팅(troubleshoot)
├───────────────────────────────┤
│ 바로 연결                     │
│ [상담원 연결]  [방문 예약]    │  handoff_card / booking
├───────────────────────────────┤
│ 최근 문의·주문 (이력)         │  status_tracker (R12)
│ • 방문 예약 #123  진행중 →    │
└───────────────────────────────┘
                          ( 💬 )
```

- **상태:** 미연동=기기 영역 자리에 연동 안내 / 이력 없음=빈 메시지.
- "증상/모델로 찾기" → 채팅 패널을 **troubleshoot 흐름**으로 열고 화면 맥락 전달(R9-4).

## 4. S3 — AI 채팅 패널 (전역)

핵심 화면. 메시지 = `text` + `template` + `media` + `ctas` 합성(R11).

```
┌───────────────────────────────┐
│ ⌄ AI 어시스턴트          ✕    │  핸들(바텀시트) + 닫기
│  (진행 흐름: 세탁기 해결중)   │  active_flow 표시 (R6)
├───────────────────────────────┤
│  🧑 세탁기에서 소리가 나요     │  사용자 메시지
│      [📷 첨부 이미지]          │  멀티모달 입력 (R10)
│                               │
│  🤖 점검해보니 배수 필터…      │  text
│   ┌─ device_status ─────────┐ │  템플릿 렌더
│   │ 세탁기 · 오류 5E         │ │
│   └─────────────────────────┘ │
│   ┌─ guide_steps ───────────┐ │
│   │ 1. 전원 끄기 [▶ 영상]    │ │  step.media (R10)
│   │ 2. 필터 분리 …           │ │
│   └─────────────────────────┘ │
│   ┌─ choices ───────────────┐ │  인터랙션 (R4-3·R7)
│   │ 어떤 필터인가요?         │ │
│   │ ( ) A형  ( ) B형         │ │
│   └─────────────────────────┘ │
│           [장바구니] [주문]    │  ctas
│  · · ·  (타이핑 인디케이터)    │  스트리밍 (R14)
├───────────────────────────────┤
│ [＋] 메시지 입력…        [전송]│  ＋ = 카메라/갤러리/영상
└───────────────────────────────┘
```

- **입력바:** 텍스트 + `＋`(멀티모달: 권한 요청·업로드 진행). 전송 중 비활성/취소.
- **흐름 표시:** 가이드 흐름 진행 중 상단 배지(R6). 자유 입력 시 자동 전환, 복귀 가능.
- **상태(R14·R13):** 응답 대기=타이핑 인디케이터 / 지연=대기·재시도·취소 / 연결 끊김=재연결 배너.

## 4-B. S4 — 브릿지 모달 (카드 탭 경량 설명)

홈/알림 카드를 눌렀을 때, 간단하면 대화 대신 이 모달로 끝낸다(`bridge` 템플릿, `response-templates.md` §9).

```
        ┌───────────────────────────┐
        │ 세탁기 · 배수 필터 교체 시기 ✕│  title
        ├───────────────────────────┤
        │ 필터 수명 약 15% 남았어요.    │  summary (LLM 생성 가능)
        │ 곧 교체하시는 게 좋아요.      │
        │ ┌───────────────────────┐ │  detail = device_status (끼워 재사용)
        │ │ 세탁기 · 필터 80% 사용  │ │
        │ └───────────────────────┘ │
        │        [지금 재주문]        │  ctas (즉시 행동)
        │   ─────────────────────    │
        │  💬 AI에게 자세히 물어보기 → │  escalate → S3 (맥락 주입)
        └───────────────────────────┘
```

- **바텀시트/모달** 오버레이. 대화 세션을 열지 않는다(단발).
- 두 갈래 출구: **즉시 행동 CTA**(되돌릴 수 없으면 `confirmation` R17) / **에스컬레이션**(→ S3, P→R 전이).
- **분기**: 카드 탭 → BE가 간단(S4)/복잡(S3)을 **동적 판단**.
- 상태: 로딩=스켈레톤 / 조회 실패=텍스트 폴백 또는 바로 S3 안내(R13).

## 5. 채팅 내 인터랙션 템플릿 (배치)

```
confirmation (R17)              booking (R18)
┌─────────────────────────┐    ┌─────────────────────────┐
│ 결제를 진행할까요?       │    │ 방문 일정 선택           │
│ 배수필터 1개 · 12,000원  │    │ ( ) 6/12 10:00          │
│      [취소]  [결제하기] │    │ ( ) 6/12 14:00          │
└─────────────────────────┘    │ ( ) 6/13 09:00 (마감)   │
order_summary → checkout 확인   │            [예약 확정]   │
                                └─────────────────────────┘
status_tracker (R12)
┌─────────────────────────┐
│ 주문 #123  배송중        │
│ ●─결제 ●─발송 ○─도착     │
└─────────────────────────┘
```

- 인터랙션 회신(선택·확정)은 후속 요청으로 전송 → `FlowState` 반영(`response-templates.md` §8).
- 되돌릴 수 없는 확정(`confirmation`/`booking`)은 ActionGate(R17) 경유.

## 6. 화면 전역 규칙

- **전역 채팅 진입(FAB)** — 모든 화면에 떠 있고, 누르면 S3 오버레이 + 현재 화면 맥락 주입(R9-4).
- **상태 4종** — 모든 리스트/템플릿에 로딩(스켈레톤)·빈·에러·재시도 정의(R13·R14).
- **미연동 사용자** — 기기 의존 영역은 연동 유도로 폴백(R13).
- **플레이스홀더** — 색·간격·타이포는 토큰 참조, 애셋 도착 시 값만 교체(`frontend-architecture.md` §6).

## 7. 미해결 / 검증

- 합의된 단순 유저 시나리오를 위 화면에 매핑해 **빠진 화면·상태**가 없는지 점검(스펙 피드백 루프).
- 디자이너와 **와이어프레임 소유권** 조율 후, 비주얼은 이 구조 위에 입힌다.
