# ADR-0024: 요청 라우팅 = BE 소유, "LLM 미경유"는 커밋에 한정

- **상태**: 채택
- **관련**: `docs/architecture.md` §8, `docs/response-templates.md` §8, R17

## 배경
"LLM을 타는지 도메인을 타는지"의 라우팅 판단을 누가 소유할지, 그리고 **CTA(버튼)는 곧 LLM 미경유인지**.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | **FE/BFF가 라우팅 판단**(CTA=항상 결정적 경로) | FE가 빠른 경로 선택 | 도메인 라우팅이 FE에 새어 결합·불투명성 붕괴, CTA 설명/이유 요청도 LLM 못 탐 |
| **B (선택)** | **BE(오케스트레이터)가 라우팅 소유**, LLM 미경유는 **되돌릴 수 없는 커밋**(결제·주문·예약 확정)에만 | 관심사 분리, 대화형 CTA도 LLM 활용 | FE는 채널만 선택 |

## 결정
**B.** FE는 **상호작용 유형**(자유 입력·대화형 CTA·커밋)만 알고 **채널**을 고른다. 대화형 CTA(제안 칩·`choices`/`confirmation`/`booking` 회신·"왜 추천?")는 **`/chat` 재진입 → LLM 가능**. **커밋만** 결정적 엔드포인트 직행 + ActionGate(R17).

## 기각 이유
- A: "CTA=LLM 미경유"는 틀림 — 그러면 설명·이유 요청 같은 대화형 CTA가 LLM을 못 탄다. 라우팅이 FE에 새면 계층 결합.

## 결과/영향
LLM 미경유 보장은 **커밋 자체에 한정**. ActionGate 상세는 ADR-0033.
