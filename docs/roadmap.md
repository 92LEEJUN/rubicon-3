# 확장 로드맵 / 후보 우선순위 (Roadmap)

> 세션에서 다룬 것(capability 라우팅·멀티테넌트·mock 모드·스트리밍·신원 계약·문서)과 이미
> 백로그에 적은 후속(§8~11 prose·analytics 싱크·게스트 머지·실 SSO·order 영속)은 제외한
> **신규 확장 후보**와 임팩트×난이도 정렬. 기획 참고용(진행 시 각 항목은 `specs/<작업>/`로 승격).

크기: **S**(작음)·**M**(중간)·**L**(큼).

> **사용자 관점.** 이 후보들을 **페르소나·라이프사이클 저니**에 매핑한 사용자 렌즈 문서는
> [`docs/user-journey.md`](user-journey.md) 다(어느 페르소나의 어느 단계 JTBD를 채우는지).

> **보류(사용자 지정).** 의도적으로 미룬 항목(part_ids 매핑·실 SSO·레이턴시 pre-paint)은
> [`docs/deferred.md`](deferred.md)에 별도 인덱스로 기록한다(여기서 중복하지 않음).

## 전체 카테고리 인덱스
- **A. AI·오케스트레이션**: RAG·능동 clarify·plan 가시화·피드백 루프·다국어·요약 고도화
- **B. 멀티모달**: 이미지 진단·OCR·STT/TTS·QR/바코드·영상·AR
- **C. 개인화·추천**: 소진 예측 재주문·임베딩 추천·번들·프로모션·에너지 코칭·환경 연동
- **D. O2O·커머스**: 결제·구독·설치 매칭·반품/환불·배송 추적·보상판매·장바구니·픽업
- **E. 진단·CS**: 예지보전·리콜 매칭·워런티 자동조회·에러코드 사전·셀프수리·수리비 계산
- **F. 컴패니언·리텐션**: 알림 채널·점검 리마인더·재관여 ML·NPS·open-loop 자동화
- **G. 신뢰·안전·규정**: 개인정보 권리·PII 마스킹·감사 로그·인젝션 방어·레이트리밋·가드레일·보존정책
- **H. 운영·플랫폼**: 관측성·비용 모니터링·피처 플래그·큐/배치·헬스체크·분산·배포전략
- **I. 데이터·분석·실험**: 대시보드·A/B·지식 관리 UI·DW 적재
- **J. FE·UX**: 히스토리/검색·다크모드·접근성·i18n·PWA·반응형·편집/공유·칩 한글명·알림센터
- **K. 통합·생태계**: SmartThings·캘린더·지도·빅스비·메신저 채널
- **L. 개발자 경험·품질**: 계약 테스트(Pact)·E2E(Playwright)·실 LLM 평가 CI·스키마→타입 생성·부하 테스트·스토리북

## 추천 착수 순서
1. **신뢰·안전 베이스라인(G)** — 현재 거의 비어 프로덕션 전 필수. **← 본 라운드 스펙 착수** (`specs/trust-safety-baseline/`).
2. 멀티모달 진단(B) — 차별화 데모.
3. 실 RAG + 예지보전 + SmartThings(A·E·K) — 컨시어지 본질.
4. 관측성·분석(H·I) — 개선 루프 토대.
