# ADR-0012: 계획 = 단일 패스 (재계획 루프 없음)

- **상태**: 채택
- **관련**: `docs/agents.md` §1·§3·§4

## 배경
슈퍼바이저가 위임·실행 후, 리뷰 결과에 따라 **다시 계획/재실행**할지(반복) 아니면 한 번에 끝낼지.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (선택)** | **단일 패스** — 위임→실행→(조건부 리뷰)→조립, 반복 없음 | 지연 예측 쉬움, 비용 상한 명확 | 자동 품질 보정 없음 |
| B | **리뷰 실패 시 1회 재시도** | 품질↑ | 지연↑(한 단계 더) |
| C | **반복 재계획**(슈퍼바이저가 필요시 루프) | 품질↑↑ | 지연/비용 가변·예측 어려움 |

## 결정
**A — 단일 패스.** 리뷰 위반은 재실행 루프 대신 **안전 폴백/사람 연결**(R18)로 처리.

## 기각 이유
- B·C: 멀티에이전트는 이미 직렬 누적으로 느린데(ADR-0008), 재시도/반복은 지연·비용을 가변적으로 키운다. 지연 예측성을 우선.

## 결과/영향
지연 상한이 예측 가능해져 SLA 등급(ADR-0008)을 잡기 쉽다. 품질은 조건부 리뷰(ADR-0011)와 가드레일로 확보.
