# 사용자 저니 & 기능 기회 (User Journey)

> **기반 문서 (공유).** 제품을 **사용자 관점**에서 정의한다 — 페르소나 · 페르소나별 풀 라이프사이클 저니 ·
> 단계별 JTBD(할 일)/현재 커버리지/기능 기회. 기술 설계는 `docs/architecture.md`, 화면은
> `docs/wireframes.md`, 요구사항은 `specs/*/requirements.md`, 확장 후보는 `docs/roadmap.md`,
> 운영 준비도는 `docs/production-readiness.md` 를 본다.
>
> **읽는 법.** §2 페르소나 → §3 페르소나별 풀 저니(누가·언제·무엇을 원하고 지금 어디까지 되나) →
> §4 가로지르는 테마 → §5 기능 기회 백로그(우선순위·roadmap 매핑). 표기: ✅ 다룸 · 🟡 부분 · ⬜ 비어있음.

제품 한 줄: **삼성 가전 AI 컨시어지 — 이상감지 → 해결가이드 → 부품주문을 한 곳에서 완결.**

## 1. 라이프사이클 8단계 (공통 골격)

| | 단계 | 사용자 상황 | 현재 |
|---|---|---|:--:|
| **A** | 인지·구매 전 | 제품/문제를 알게 됨 | 🟡 |
| **B** | 온보딩·기기연결 | 앱 진입·SmartThings 연동 | 🟡 |
| **C** | 일상 사용 | 홈 진입·상태 모니터링 | ✅ |
| **D** | 이상·문제 발생 | 고장·증상 인지 | ✅ |
| **E** | 해결·수리 | 가이드 따라 처리·전문가 | ✅ |
| **F** | 부품·소모품 | 주문·재주문·취소 | ✅ |
| **G** | 재구매·업그레이드 | 노후·신모델 | ⬜ |
| **H** | 이탈·재관여 | 리텐션·재방문 | 🟡 |

> **핵심 가치 흐름은 D→E→F**(이상→해결→주문)로 완결성이 높다(FlowState 전환/복원 R6, 확인 게이트 R17,
> 안전 경고 R23). 가장 빈 곳은 **G(재구매)·B 실연동·예지보전(D 미래예측)·H 자동화**다.

## 2. 페르소나 (확장)

> 문서엔 명시 페르소나가 없었다(암묵적). 신호(`specs/multi-tenant-state`, ADR-0049/0050, requirements)
> 로부터 **5개**를 명시화한다. 각 페르소나는 §3에서 자기만의 풀 저니를 갖는다.

### P1 — 김서연 (35, 워킹맘 · 주 사용자) 🟢 정주행 사용자
- **맥락**: 로그인 + SmartThings 연동. 세탁기·냉장고·건조기·공기청정기 보유. 바쁘고 **효율·자동화** 중시.
- **목표**: 문제를 빨리 셀프로 끝내기 · 소모품을 신경 안 쓰고 자동 관리 · 과한 알림은 싫음.
- **좌절**: 알림 피로 · "또 같은 알림" · 작은 일에 상담 대기.
- **신원**: `user_id`, 다중 기기, 개인화 활성.

### P2 — 박준호 (28, 1인가구 · 신규/탐색자) 🔵 게스트
- **맥락**: 막 이사·중고/신규 가전. **미연동·비로그인(게스트)**. 가입 마찰에 민감.
- **목표**: "이 증상 뭐지?" 빠른 검색 · 가입 강요 없이 가치 먼저 체험 · 연동 방법 알기.
- **좌절**: 온보딩이 막막 · 주문하려니 갑자기 로그인 월 → 이탈.
- **신원**: `guest_token`(격리), 주문/예약 시 로그인 강제(R2, ADR-0050).

### P3 — 이정숙 (62, 비기술 · 가끔 사용) 🟠 접근성
- **맥락**: 큰 글씨·음성 선호. 복잡한 단계·전문 용어 어려움. **상담원 연결 선호**.
- **목표**: 쉽고 큰 화면 · 말로 묻기 · 위험하면 사람이 와주기.
- **좌절**: 다단계 가이드에서 길 잃음 · 작은 버튼·전문 용어.
- **신원**: 본인 또는 **가족 대행 연동**(P4와 교차).

### P4 — 최민재 (40, 가족 공유 · 비주 사용자) 🟣 멀티테넌트
- **맥락**: **부모님 집 기기를 원격 관리**. 가끔 사용. 멀티 사용자·다중 기기.
- **목표**: 내 맥락 격리(누수 없이) · 보호자로서 알림 받기·대신 주문/예약.
- **좌절**: 누구 기기인지 헷갈림 · 위임/대행 경로 없음.
- **신원**: 멀티테넌트(ADR-0049/0050), 기기 격리(R27).

### P5 — 운영자/CS팀 (내부) ⚙️ 백오피스
- **맥락**: 제품 개선·비용·CS 부하 가시성. 저니가 아닌 **운영 루프**(§3-말미).
- **목표**: 퍼널·전환·체류(R28) · LLM 비용/쿼터(S6) · 실험(S8) · 콜센터 부하↓.

## 3. 페르소나별 풀 라이프사이클 저니

> 각 표는 그 페르소나가 **남들과 갈라지는 지점**과 기회에 집중한다(공통 커버리지는 §1).

### P1 김서연 — "빠르고 자동으로" (정주행)
| 단계 | 그녀의 행동·기대 | 현재 | 기회 (페르소나 특화) |
|---|---|:--:|---|
| A 인지 | 소모품 떨어질 때 알아서 추천 | 🟡 | 정기구독·번들(필터+세제), 소진 예측 재주문 |
| B 온보딩 | 이미 연동, 기기 추가만 | ✅ | 신규 기기 원터치 등록 |
| C 일상 | 아침에 홈 브리핑 훑기 | ✅ | 에너지 코칭·정기 점검 리마인더 |
| D 이상 | **푸시로** 즉시 알기 | 🟡 | 실 푸시 채널, **예지보전**("다음주 필터 교체 예상") |
| E 해결 | 바쁘니 셀프로 빨리 | ✅ | 인라인 영상 가이드, 소요시간 표기 |
| F 부품 | 1클릭 재주문 | ✅ | 구독·배송 추적·반품 안내 |
| G 재구매 | 노후 기기 교체 시점 | ⬜ | 보유→신모델 업그레이드 알림, 보상판매 |
| H 재관여 | **과한 알림 싫음** | 🟡 | Engagement 기반 중복 필터·빈도 제어(알림 피로↓) |

### P2 박준호 — "막막한 신규" (게스트·온보딩이 승부처)
| 단계 | 그의 행동·기대 | 현재 | 기회 (페르소나 특화) |
|---|---|:--:|---|
| A 인지 | 검색/딥링크로 유입 | 🟡 | 증상→제품 진입, SEO/공유 링크 |
| B 온보딩 | **연동 방법을 모름** | ⬜ | **SmartThings OAuth 단계 가이드(QR·스크린샷)**, 게스트로 가치 먼저 |
| C 일상 | 아직 습관 없음 | ⬜ | 첫 성공 경험 → 로그인 유도(가치 후 가입) |
| D 이상 | 증상 검색이 첫 접점 | ✅ | **비연동 증상 진단** 강화(기기 없이도) |
| E 해결 | 셀프 가이드 따라감 | ✅ | 모델 모를 때 사진으로 식별(멀티모달) |
| F 부품 | 주문하려니 **로그인 월** | 🟡 | 게스트 장바구니 → **로그인 후 이어가기**(merge 이미 있음, UX 매끄럽게) |
| G/H | (아직 신규) | ⬜ | 첫 주문 후 재관여 시드 |

### P3 이정숙 — "쉽고 사람이" (접근성)
| 단계 | 그녀의 행동·기대 | 현재 | 기회 (페르소나 특화) |
|---|---|:--:|---|
| A 인지 | 가족이 알려줌 | 🟡 | 가족 초대·대행 |
| B 온보딩 | **가족이 대신 연동** | ⬜ | 가족 위임 연동, 보호자 링크 |
| C 일상 | 큰 화면·간단 요약 | 🟡 | **접근성(a11y): 큰 글씨·고대비·음성**, 쉬운 모드 |
| D 이상 | 말로 묻기 | 🟡 | **음성 입력(STT)**, 평이한 언어 |
| E 해결 | 복잡하면 사람 호출 | ✅ | **원터치 상담/방문**(danger 아니어도 선택지 상단) |
| F 부품 | 확인이 더 분명하길 | ✅ | 확인 단계 단순·명확(큰 버튼·재확인 음성) |
| G/H | 가족이 관리 | 🟡 | 보호자에게 위임 알림 |

### P4 최민재 — "부모님 집 원격" (멀티테넌트·위임)
| 단계 | 그의 행동·기대 | 현재 | 기회 (페르소나 특화) |
|---|---|:--:|---|
| A 인지 | 부모님 기기 노후 파악 | 🟡 | 가구별 기기 인벤토리 |
| B 온보딩 | **부모님 기기 위임 연동** | ⬜ | 가족 그룹·위임 권한(RBAC 스캐폴드 S7 위) |
| C 일상 | 여러 가구 원격 모니터링 | 🟡 | **다중 가구/위임 보기**, 가구 전환 |
| D 이상 | 부모님 대신 알림 수신 | 🟡 | **보호자 알림 라우팅**(대상자≠수신자) |
| E 해결 | 원격으로 판단·수배 | ✅ | 원격 진단(SmartThings 실), 방문 대행 예약 |
| F 부품 | **대신 주문/결제** | 🟡 | 위임 주문·결제, 대상 가구 청구 |
| G 재구매 | 부모님 기기 교체 | ⬜ | 노후 기기 교체 제안(가구 단위) |
| H 재관여 | 가끔 점검 | 🟡 | 보호자용 주간 요약 |

### P5 운영자 — 운영 루프(저니 아님)
```
수집(R28 퍼널·전환·체류, 가명화) → 분석(전환 기여 0037·세션 샘플링 0041)
  → 비용 관측(S6 /metrics/llm) → 실험(S8 A/B로 가설 검증)
  → CS 부하·핸드오프율 모니터(0063 감사) → 제품 개선 → (다시 수집)
```
기회: 실 대시보드(BI)·DW 적재(roadmap I) · NPS/만족도 수집 · CS 부하 지표화.

## 4. 가로지르는 테마 (기능 고려의 축)

1. **선제성(Proactivity)** — 현재는 "현재 상태"만. **예지보전**(텔레메트리+예측)이 최대 미개척 가치(P1·P4). roadmap E·K.
2. **신뢰·투명성(Trust)** — 안전 게이트(R17·R23)는 있으나 **프라이버시 센터(동의 가시성·삭제, S5 위)·배송/반품 투명성**이 비어 사후 이탈(전 페르소나).
3. **개인화(Personalization)** — Engagement 기록(R29)은 있으나 **선제 생성 전 중복 필터·이력 화면**이 없어 알림 피로(P1)·재참조 손실.
4. **접근성(Accessibility)** — **현재 비어있음**. 큰 글씨·음성·쉬운 모드(P3). roadmap J.
5. **온보딩·활성화(Activation)** — **실 SSO·연동 가이드 부재**가 신규 전환의 병목(P2·P4). roadmap B.
6. **연속성(Continuity)** — 핸드오프 맥락·이력은 구조만. **상담원 이어보기·히스토리 탭**(전 페르소나).

## 5. 기능 기회 백로그 (사용자 렌즈 · 우선순위)

> 임팩트(사용자 가치×사업)·난이도·페르소나·라이프사이클·roadmap 매핑. 진행 시 `specs/<작업>/`로 승격.

### 우선 (높은 임팩트 / 낮음~중간 난이도)
| 기회 | 페르소나 | 단계 | roadmap | 비고 |
|---|---|---|---|---|
| **알림 중복 필터·빈도 제어** | P1 | H | F | 선제 생성 전 Engagement 조회 → 알림 피로↓·리텐션 |
| **온보딩 OAuth 단계 가이드** | P2·P4 | B | B | 신규 활성화 병목 제거(게스트→로그인 매끄럽게) |
| **히스토리 탭**(주문·대화·서비스 통합) | 전체 | C·H | F·J | 이력(R12) 노출 부재 → 재참조·재주문 |
| **배송 추적 + 반품 안내** | P1·P2 | F | D | `status_tracker` 확장 → 구매 확신·사후 이탈↓ |
| **부품 호환성 선택지** | 전체 | F | C·E | 모호 매칭(R4-3) → 신뢰도·전환↑ |
| **NPS/만족도 인라인 수집** | 전체 | E·H | F·I | 해결 확인(R25)에 "왜?" → 제품 데이터 |
| **접근성 베이스(큰글씨·음성 입력)** | P3 | C·D | J·B | 현재 0 → 고령/비기술 포용 |

### 전략 (높은 임팩트 / 높은 난이도)
| 기회 | 페르소나 | 단계 | roadmap | 비고 |
|---|---|---|---|---|
| **예지보전**(소모품·고장 예측) | P1·P4 | D | E·K | 선제 가치의 본질 — SmartThings 실 텔레메트리 전제 |
| **실 RAG 지식베이스** | 전체 | D·E | A | "진짜 컨시어지" 정답률·근거 |
| **멀티모달 이미지 진단** | P2 | D·E | B | 모델 모를 때 사진 식별 |
| **가족 그룹·위임**(보호자) | P3·P4 | B·D·F | F·G | 멀티테넌트 위에 권한·알림 라우팅 |
| **재구매·보상판매** | P1·P4 | G | D·C | **현재 전무** — 노후→신모델, trade-in |
| **프라이버시 센터** | 전체 | 신뢰 | G | 동의 가시성·삭제(S5 DSR 위 FE) |

### 여유/탐색
구독·번들(P1, F·C) · 에너지 코칭(P1, C) · 다중 가구 보기(P4, C) · 비연동 증상 진단 강화(P2, D) · 영상 가이드(P1, E).
