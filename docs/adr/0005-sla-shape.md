# ADR-0005: SLA = 목표+관측+오토스케일 (능동 강등 안 함)

- **상태**: 채택
- **관련**: `docs/operations.md` §12, ADR-0004

## 배경
적응형 강등을 제외(ADR-0004)했으므로, 요청 내부에서 품질을 낮춰 지연을 맞추지 않는다. 그러면 SLA를 어떤 성격으로 둘지.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (선택)** | **목표 + 관측 + 오토스케일** — SLA는 목표값으로 두고, 초과는 워커 오토스케일로 해소(요청 내부 품질 저하 없음) | 품질 일관, 운영으로 흡수 | 인프라 스케일 필요 |
| B | **능동 강등으로 지연 목표 강제** | 지연 상한 보장 | **품질 희생**(ADR-0004와 충돌) |

## 결정
**A.** 목표값(초안): 첫 토큰 p95 ≤ 2s · 완료 p95 ≤ 12s(단일 LLM 경로) / 결정적 조회 p95 ≤ 300ms. 과부하는 수용+점진 렌더+오토스케일로 해소, **붕괴 방지 하드캡** 도달 시에만 소프트 폴백. 끊김/타임아웃은 abort+폴백.

## 기각 이유
- B: 품질 일관성(ADR-0004)을 깨므로 제외.

## 결과/영향
멀티에이전트는 단일 목표가 안 맞아 **진행 지표로 재정의**(ADR-0008): 첫 섹션 ≤2~3s, 완료는 별도 등급(p95 ≤15~20s).
