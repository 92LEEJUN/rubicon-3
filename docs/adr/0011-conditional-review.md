# ADR-0011: 리뷰/크리틱 = 조건부

- **상태**: 채택
- **관련**: `docs/agents.md` §3, `docs/llm-policy.md`

## 배경
리뷰(크리틱) 에이전트를 언제 돌릴지. 리뷰는 추가 LLM 호출이라 비용·지연이 든다.

## 후보안
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (선택)** | **조건부** — 안전(R23)·커밋(R17)·불확실(R16) 경로만 | 위험 경로 보호 + 비용·지연 절감 | 발동 기준 관리 필요 |
| B | **항상** — 모든 응답 리뷰 | 안전 최대 | **비용·지연 ×매턴** |
| C | **미적용** — 가드레일 프롬프트로 대체 | 비용 0 | 안전·근거 검증 약화 |

## 결정
**A — 조건부.** 안전 경고 포함·되돌릴 수 없는 커밋·근거 불확실일 때만 최종 직전 게이트. 일반 정보성은 스킵.

## 기각 이유
- B: 모든 턴 리뷰는 비용·지연이 과하다(대부분 정보성 응답엔 불필요).
- C: 주문/안전 경로의 검증이 빠져 리스크.

## 결과/영향
단일 패스(ADR-0012)와 정합 — 리뷰 위반 시 재실행 루프 대신 **안전 폴백/사람 연결**(R18). 발동 임계는 구현 단계 확정.
